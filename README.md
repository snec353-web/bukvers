# Букверс

Больше, чем книги: персональные сказки, истории с выбором, книги за 15 минут и сериалы.

Сайт: https://snec353-web.github.io/bukvers/

## Как поменять тексты

Все тексты сайта и демо-истории лежат в файле `data.js`.
После изменений поменяйте номер версии `bukvers-v1` в `sw.js`, чтобы у читателей обновился сохранённый сайт.
